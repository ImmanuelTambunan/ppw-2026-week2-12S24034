## Deskripsi Singkat
Halaman web ini merupakan portofolio *single-page* interaktif yang memuat informasi profil pengembang, rekapitulasi proyek dalam bentuk tabel semantik dan daftar terstruktur, serta formulir pemesanan konsultasi yang memenuhi standar aksesibilitas WCAG 2.2 Level AA.

## Checklist Fitur & Kebutuhan Teknis
- [x] **Struktur Semantik HTML5:** Memanfaatkan `<header>`, `<nav>`, `<main>`, `<section>`, `<aside>`, dan `<footer>`.
- [x] **Penyajian Data:** Memuat `<table>` semantik lengkap (`<caption>`, `<thead>`, `<tbody>`, `<tfoot>`, atribut `scope`) serta kombinasi list (`<ul>` & `<ol>`).
- [x] **Formulir Interaktif & Accessible:** Terdiri dari 2 `<fieldset>`, `<legend>`, 6 tipe input (`text`, `email`, `tel`, `number`, `radio`, `checkbox`, `select`, `textarea`), dan pasangan `<label for="...">` eksplisit.
- [x] **Estetika CSS Modern:** Menggunakan Universal Box Reset, aturan warna 60-30-10, Flexbox Layout, dan Media Queries responsif.
- [x] **Deployment:** Dipublikasikan melalui GitHub Pages.
